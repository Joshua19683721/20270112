[AutoShape 414] 聲音、光的應用 / 
[AutoShape 822] 光的特性 / 
[AutoShape 897] 本身能發光的物體，稱為( 光源 )，例如太陽、點燃的蠟燭。 / 光是(直線行進)的，遇到不透明的物體時，會被阻擋而形成(  影子  )。 / 相對位置：光源→(　物體　)→影子。 / 
[AutoShape 901] 聲音的產生和傳播 / 
[AutoShape 1076] 聲音是由物體振動產生，振動小發出的聲音較( 小 )；物體振動大，發出的聲音較( 大 )；物體振動停止，聲音也會停止。 / 聲音可以透過空氣、液體以及( 固體 )傳播。 / 氣體傳播：物體振動時，會使周圍的空氣隨著振動，並將聲音傳達到我們的耳朵。 / 液體傳播：例如海豚的聲音可以透過水傳播，幫助海豚溝通。 / 固體傳播：例如耳朵貼在門板上可以聽到門外的聲音。 / 
[AutoShape 1084] 利用聲與光可以達到警示、指示、裝飾或娛樂等目的。 / 警示或指示：腳踏車車鈴、一氧化碳偵測警報器、( 燈塔 )、路燈、救護車警示燈、行人穿越號誌等。 / 裝飾或娛樂：聖誕燈飾、熱氣球光雕音樂會、聲光玩具等。 /  / 
[AutoShape 917] 光照射到鏡子時，會改變行進方向，產生( 反射 )現象。 / 反射的光也是直線行進的。 / 光照射到像不鏽鋼杯、玻璃帷幕等平滑、光亮的物品，也可產生像鏡子一樣的反光現象。 / 光的反射應用：照鏡子、利用後視鏡或反光鏡注意路況、腳踏車的反光板、道路上的( 反光桿 )、反光背心等。 /

[AutoShape 379] 好玩的電路 / 
[AutoShape 1061] 電的應用 /  / 
[AutoShape 1099] 通電後會動的物品，裡面通常有小馬達等動力構造。 / 小馬達通電後會轉動，若將電池正極、負極反過來連接，小馬達的轉動方向會（ 相反 ）。 / 
[AutoShape 1104] 生活中，有些物品使用電池，有些物品使用電力公司傳送的電力。 / 電池電量用盡後要送到指定地點回收，以免造成環境汙染。 / 
[AutoShape 1098] 小馬達 / 
[AutoShape 897] 電池作為電源提供電力，電池凸起的一端是（ 正極 ）；平的一端是負極。 / 電線是電流傳輸的通道，外面是塑膠皮，裡面是（ 銅線 ）。 / 傳統燈泡的外面是玻璃罩，裡面的燈絲是發亮部位。 / 將燈泡的螺紋金屬體和接點分別用電線連接或直接接觸電池的正極和負極，燈泡就會發亮。 / 電路連接成功，電流通過使燈泡發亮，稱為（ 通路 ）；電路沒有接好，電流無法通過，燈泡不會發亮，稱為（ 斷路 ）。 / 
[AutoShape 1060] 電路連接 / 
[AutoShape 822] 串聯與並聯 / 
[AutoShape 1096] 數個燈泡或電池串接在同一個通路上，這種接法稱為串聯。 / 數個燈泡或電池分別接在不同通路上，這種接法稱為並聯。 / 電池串聯可增加電力，燈泡亮度（ 增加 ），其中一個電池沒接好，燈泡就不會亮。 / 電池並聯可以讓電力更持久，燈泡亮度（ 不變 ），其中一個電池沒接好，燈泡仍然會亮。 / 燈泡（ 串聯 ）時，燈泡亮度會減弱，其中一個燈泡沒接好，全部燈泡都不會亮。 / 燈泡（ 並聯 ）時，燈泡亮度不變，其中一個燈泡沒接好，其他燈泡仍然會亮。 /  / 
[AutoShape 1103] 連接在電路中，能形成通路使燈泡發亮的物品，稱為電的（ 良導體 ），大多為金屬物品，例如迴紋針、硬幣等。 / 連接在電路中，形成斷路而不能使燈泡發亮的物品，稱為電的不良導體，大多為非金屬製品，例如橡皮筋、紙團等。 / 控制電路形成通路或斷路，可以使燈泡亮或不亮。 /
